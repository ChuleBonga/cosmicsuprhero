# Rejected generated images — QA record, 17 November 2026

Two image-generation attempts were made while seeking a single caretaker look-development reference. Neither followed the intended brief. Both produced elaborate **promotional production boards** rather than a standalone, consistent character reference.

Failures:
- Multiple unrelated panels, user-interface labels, fictitious location names, invented character names, artificial statistics/progress bars and implied deployment status.
- Architecture, ornamentation and facial designs diverged toward generic fantasy/sci-fi instead of matching exact user-provided original civilization reference imagery.
- No valid single character turntable, proportion lock, UV guide, rig-ready multi-view source or evidence of one consistent subject.
- Such outputs would be unusable as a production NPC reference and risk laundering visually attractive but misleading artifacts into the game's asset library.

**Disposition:** REJECTED, NOT INTEGRATED, NO PERFORMANCE OR PRODUCTION STATUS CLAIMS. Do not treat these pictures as completed art, maps, characters, UI designs, or real game screenshots.

**Corrective rule:** Do not regenerate another general game-design board. Acquire and version source-of-truth civilization references; run one-object-one-subject image generation through an explicitly controlled and inspectable prompt only when the generation service's credit usage is authorized. If the result cannot pass front/side/back identity and costume-consistency checks, reject before 3D reconstruction. Cost quote recorded for a controlled single image candidate: 0.25 Higgsfield credits, *not spent*. Any 3D reconstruction/rigging may incur separate credits and would need its own cost preflight and approval.

No generic stock human model or assembled emoji/infographic may be labeled an Arcturian NPC. Diagnostic GLBs are permitted only in test tooling with correct attribution.
