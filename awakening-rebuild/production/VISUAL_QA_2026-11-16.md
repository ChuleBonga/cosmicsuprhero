# Art and interaction QA: real Chromium captures
**Review date:** November 16, 2026
**Evidence:** GitHub Actions run 43999277243, artifact `arcturian-browser-qa`. Captures: `desktop-1440.png` (first view at 1440×900), `mobile-390.png` (390×844, after hearing Caretaker). Both are full-page screenshots.
**Art verdict: REJECTED.** The build passed technical checks, but the experience does not yet match the game brief.

## Observed on desktop
- The giant serif heading and dark navy palette are legible and restrained, but the red celestial sphere lands directly behind the headline and supporting text. This is an avoidable compositional collision.
- The opening reads as a cinematic web page or pitch deck, not as a place the player occupies.
- No world geography, inhabitant, character expression, object interaction, diegetic evidence or playable body is visible.
- The three witness cards read as a desktop questionnaire. They are identical in layout and do not establish cultural identity, place, voice, or occupation.
- The long vertical separation between introduction and witness cards creates dead visual space without narrative purpose.

## Observed on 390px mobile, after one account
- Body copy, controls and content fit the viewport, without obvious horizontal clipping.
- The mobile header and evidence cards consume a long continuous scroll. This is not a mobile game interface.
- The red sun overlaps the introduction copy; placing a dramatic background behind copy is not a replacement for authored location art.
- Programmatic focus on the chapter heading produced a prominent browser focus box around the oversized heading. Corrected in a follow-up CSS change; visual recheck required.
- The cards convey progress through UI state, but no character performance, nearby player action or return to a changed location is shown.

## Technical test results
- Chromium browser tests: 3/3 passed. Covered failed deduction/recovery, protect/disclose branches, saved reload, Enter interaction, minimum button height, no mobile horizontal overflow, and screenshot capture.
- Source: https://github.com/ChuleBonga/cosmicsuprhero/actions/runs/43999277243
- The separate external cloud-browser public-url check failed with ERR_SOCKS_CONNECTION_FAILED. The app was not observed by that browser. Chromium CI evidence is available.
- Current Vercel QA project deployment reached READY but is not equivalent to an art-qualified release.

## Required actions
1. **Do not promote or release the editorial prototype as a game.**
2. Obtain exact visual source-of-truth references to create one character/settlement art bible, retaining the approved cobalt-red-ochre color relationships.
3. Build and art-review one actual rigged resident against those images. Record close-up, turntable, locomotion, facial, and silhouette comparison.
4. Build one coherent 20–30m inhabited location, not modular filler. Include two working civilian activities, one interruption, and one meaningful player interaction.
5. Join the social deduction mechanic to 3D observation, persistent NPC behavior and physical consequences.
6. Rerun the captured first screen and 390px mobile UX audit. The new composition must show the world and player immediately, rather than the witness-card dashboard.
7. Perform actual desktop/mobile performance measurements and verify fallback behavior before any promotion.
