## Three look targets
1. **Arrival:** one unambiguously Arcturian landscape and functional path, huge red sun and deep cobalt sky; evidence of inhabitants visible from the outset.
2. **Inhabited waystation:** ordinary people working and exchanging information; credible workshop and regional infrastructure; no empty stone shrine.
3. **First Contact:** real person, meaningful conversation, a grounded recording object with physical function, human-scale cinematic framing.

Use same camera height/lens target in code and keyframe for honest comparison. Each visual target is reviewed at desktop and portrait mobile crop, at actual gameplay scale.

## Rights and approval
The board's reference pictures are research only. No mood-board files go into public builds without tracked rights. Keep original scene prompts, edit history, source files, commercial usage status and approval evidence for all derived assets.
