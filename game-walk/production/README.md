# Asset production & quality governance

The production documentation lives here so it stays attached to the actual `main` game code and survives chat handoffs.

- [Vision and quality contract](VISION_AND_QUALITY_GATES.md): non-negotiable identity, evidence and release gates.
- [Asset-led production plan](PRODUCTION_PLAN.md): gated roadmap for first inhabited slice to album promotion.
- [Asset register](ASSET_REGISTER.csv): **120 tracked deliverables**, dependency / status / format / evidence fields.
- [Asset register guide](ASSET_REGISTER_README.md): interpretation, review states and priorities.
- [Reference matrix](REFERENCE_MATRIX.md): use/not-copy relationship between private inspirations and asset families.
- [Creative decision log](DECISIONS.md): prevents speculative story or cultural assumptions from silently becoming canon.
- [Review template](ART_REVIEW_TEMPLATE.md): pass/fail criteria and evidence record.
- [Visual generation log](VISUAL_GENERATION_LOG.md): image output acceptance and rejection.

The user prefers to see work on the actual live site, not isolated feature branches. **This directory is source-controlled on `main` but not published as visitor content**. Only explicitly accepted, tested work is integrated into the live game; legacy music-site routes and pre-save must continue working.

See `../experiments/first-person/DESIGN.md` for previously recorded art references and gameplay contracts. This production pack supersedes any older rule implying Vercel deployment success equals art acceptance.
