# Art review 02 · Remove obstructing monuments and inspect the actual character

**Status: review-only; creative approval still BLOCKED.**

The most recent `main` branch already contains a reference-controlled indigo/ochre terrain study, original album-color comparison, and a CC0 rock normal/roughness map. These remain unapproved. The latest review specifically identified that a giant generic gateway occludes the scarlet sun, while a distant ring appears unrelated to the inhabited civilization. Both also shift attention away from the official cover's powerful geology.

For `?art-review=arrival&look=cover` only, the unapproved gateway and distant ring are now suppressed. The standard public game remains unchanged, with its existing path/obstacle systems still operational. This is an **art-composition test**, not an assertion those structures can never be included in later approved canon.

The `?art-review=inhabitants` start camera is moved closer and aims at the **actual Blender-authored W0 model** at approximately four metres. This lets visual review detect poor anatomy, material and working behavior rather than mistaking a distant silhouette for a finished NPC. The character still appears only through an opt-in review parameter.

- Does the absent generic ring reveal useful geography, or only more empty landscape? Empty landscape is still a failed inhabited-world gate.
- Can eyes, facial shape, garments and the workbench/hand relationship actually be judged from the closer view?
- Is the character shaded as a physically present person rather than a small blue mannequin?
- Do mobile touch and framing hold at 390×844, with no clipping or missed interaction?
