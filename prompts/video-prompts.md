# Cosmicsuprhero Video Prompts

These prompts are for offline video generation, Blender rendering, or image-to-video tools. The live site should only receive optimized `.webm`, `.mp4`, and poster files.

## Global Video Rules

```text
No audio.
No text.
No logos.
No captions.
No watermark.
No fast camera moves.
No glitch overload.
No spinning planets.
No neon cyberpunk.
Make the first and last frame match closely enough for a smooth loop.
```
